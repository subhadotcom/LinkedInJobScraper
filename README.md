# LinkedIn Job Scraper

A Python command-line tool for scraping job listings from LinkedIn with search parameters and structured data output.

## Features

- Scrape job listings from LinkedIn based on keywords and location
- Extract key job details (title, company, location, description, etc.)
- Handle pagination to retrieve multiple pages of results
- Store data in CSV or JSON format
- Implement rate limiting and user agent rotation to avoid being blocked
- Proper error handling and retry mechanisms

## Requirements

- Python 3.6+
- Selenium
- BeautifulSoup4
- Requests
- Chrome WebDriver
