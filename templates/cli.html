Command Line Usage

The LinkedIn Job Scraper can also be used from the command line for advanced users or for automation purposes.

Usage:
python main.py [options]

Command Line Options

Option Description Required Default
--keywords Job search keywords (e.g. "python developer") Yes N/A
--location Job location (e.g. "New York", "Remote") No Empty (all locations)
--pages Number of pages to scrape No 1
--format Output format (csv or json) No csv
--output Output filename (without extension) No Auto-generated based on keywords and timestamp
--verbose Enable verbose logging No False

Examples

Basic search for Python Developer jobs (1 page)
python main.py --keywords "python developer"
Search for remote Data Scientist jobs (3 pages) with JSON output
python main.py --keywords "data scientist" --location "remote" --pages 3 --format json
Search for Software Engineer jobs in New York with custom output file and verbose logging
python main.py --keywords "software engineer" --location "new york" --output "nyc_software_jobs" --verbose
Note: The command line version will save the results to a file instead of displaying them in a web interface.
